# i18n

All copy resolves through the existing `navigation` namespace in
`src/shared/presentation/i18n/locales/{fr,en}/navigation.ts`, which today holds a
single key.

## Reused keys

No new key is needed for these; they already exist and are already used by the mega
menu, so both surfaces stay in step:

| Key | Used for |
| --- | --- |
| `general.all` | The "All" category row |
| `general.featured` | The "À la une" heading |
| `general.viewAll` | The featured block's trailing link |
| `general.popularTags` | The tag section heading |
| `articles.home.categories` | News panel section heading |
| `videos.home.categories` | Vidéos panel section heading |
| `videos.home.showsViewAll` | The "All shows" row |

The English barrel's type is the canonical key shape for the react-i18next module
augmentation, so both files must stay key-complete or the build fails.

`searchLabel` is declared now though the field is not built (see 02), so the copy
lands with the rest of the namespace rather than as a later one-off.

## Hardcoded strings to remove

`MobileNav` currently hardcodes three French strings, which is why they never switch
with the language:

```tsx
aria-label="Ouvrir le menu"          // -> t("navigation.mobileMenu.open")
aria-label="Navigation principale"   // -> t("navigation.mobileMenu.title")
<DialogPrimitive.Title>Navigation    // -> t("navigation.mobileMenu.title")
```

The nav item labels have the same problem a level up: `NAV_LINKS` in
`layouts/Header/constants.ts` hardcodes `"NEWS"`, `"VIDEOS"`, `"LYRICS"`,
`"ARTISTES"` as literals rather than i18n keys. The mobile tabs use
`MOBILE_MENU_TABS` with real keys instead. Aligning `NAV_LINKS` to keys is a separate
change and is listed in 10 as optional follow-up, since it touches `DesktopNav`.

## Hydration

Every component rendering `t(...)` here is `"use client"` and sits inside a dialog
that only mounts on interaction, so there is no server/client text mismatch and no
`suppressHydrationWarning` is needed — unlike `FeedHeading`, which renders during the
streamed server pass.
