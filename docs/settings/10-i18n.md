# i18n

Two new module namespaces — `settings` and `sessions` — registered into
`shared/presentation/i18n/resources.ts` alongside `auth`, each with `en` + `fr`
locale files under `modules/<module>/presentation/i18n/locales/`. Copy stays in
these config files, never hardcoded at call sites; toast copy lives in the module's
`*.notification.ts` (per project convention).

## `settings` namespace

Suggested file split (mirrors `auth`): `common.ts`, `nav.ts`, `menu.ts`,
`profile.ts`, `security.ts`, `account.ts`, `notification.ts`.

## `sessions` namespace

If session **device/browser/platform** labels need translating, add a small
`sessions` namespace (`sessions.device.desktop`, `sessions.browser.chrome`, …).
Otherwise the raw enum values render as-is and no namespace is required. Decide
during implementation; the values are stable strings from the backend.

## Reused existing keys

The account dropdown and sign-out confirm reuse keys that already exist:
`auth.session.signOut`, `auth.session.signOutConfirmTitle`,
`auth.session.signOutConfirmDescription`, `auth.session.signOutAll`,
`auth.common.cancel`, `navigation.login`. See the audit in the docs research or
`modules/auth/presentation/i18n/locales/*`.

## Registration

```ts
// shared/presentation/i18n/resources.ts
import { settingsMessages } from "@/modules/settings/presentation/i18n";
import { sessionsMessages } from "@/modules/sessions/presentation/i18n";

export const en = { ...sharedEn, auth: authMessages.en,
    settings: settingsMessages.en, sessions: sessionsMessages.en } as const;
// (fr mirror)
```

Add every new word (French especially) to `.cspell-words.txt` via the sync script.
