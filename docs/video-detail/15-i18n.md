# 15 — i18n

All detail-page strings live in a new **`video-detail.ts` locale file per locale**,
spread into the existing `videos` locale barrels (next to `home` / `exclusiveshow`), so
keys resolve as `t("videos.detail.*")`. No new resource wiring — the `videos` namespace
is already registered. En and fr must stay key-aligned; brand names (Facebook, X,
WhatsApp, YouTube) are proper nouns and stay untranslated.

## Key groups (`videos.detail.…`)

| Group | Keys |
|---|---|
| root | `share`, `addToPlaylist`, `backToVideos` |
| `stats` | `views`, `likes`, `comments`, `shares` (aria/tooltips for the chips) |
| `rating` | `label`, `rateAria` (with `{{stars}}`), `success.title`, `success.description`, `error.title`, `error.description` |
| `tabs` | `description`, `lyrics`, `similar` |
| `lyrics` | `empty`, `by` (artist byline label) |
| `similar` | `empty` |
| `tags` | (reuses the label pattern) `label` |
| `shareModal` | `title`, `facebook`, `x`, `whatsapp`, `copy`, `copied.title`, `copied.description` |
| `playlist` | `title`, `empty`, `create.placeholder`, `create.submit`, `created.title`, `addCount_one`, `addCount_other`, `added.title`, `added.description`, `error.title`, `error.description` |
| `sidebar` | `popular` |
| `notFound` | `title`, `subtitle` |
| `error` | `title`, `subtitle`, `retry` |

Pluralization uses i18next suffixes (`addCount_one` / `addCount_other` → "Add to 1
playlist" / "Add to {{count}} playlists"; fr mirror "Ajouter à {{count}} playlist(s)"
via `_one`/`_other`). Counts (views/likes) are **numbers formatted by `formatCount`**,
not i18n — only the labels translate.

## Shared reuse

- The relative date and `readTime`-style patterns come from existing shared/videos keys
  where present; nothing video-card-level is redefined.
- `SocialShareGroup` takes its aria-labels via props, so the article rail keeps
  `articles.share.*` and the video modal supplies `videos.detail.shareModal.*` — the
  component stays namespace-agnostic.

## Registration

`videos/presentation/i18n/locales/{en,fr}/video-detail.ts` exporting a `videoDetail`
object with a single `detail` root key, spread into each locale barrel
(`...videoDetail`) exactly as `articleDetail` is in the articles module. Structural
parity between en and fr is mandatory.
