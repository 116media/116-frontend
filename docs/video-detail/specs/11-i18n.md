## 2. French mirror (`fr/video-detail.ts`)

Identical keys, natural copy — e.g. `share: "Partager"`, `addToPlaylist: "Ajouter à une
playlist"`, `stats.views: "Vues"`, `rating.rateAria: "Noter {{stars}} sur 5"`,
`tabs.similar: "Vidéos similaires"`, `lyrics.empty: "Aucunes paroles disponibles pour
cette vidéo."`, `playlist.addCount_one/other: "Ajouter à {{count}} playlist(s)"` split
naturally, `sidebar.popular: "Vidéos populaires"`, `notFound.title: "Vidéo
introuvable"`.

## 3. Barrels

Spread `...videoDetail` into `locales/en/index.ts` and `locales/fr/index.ts` beside the
existing `home`/`exclusiveshow` entries; update each barrel's JSDoc. No change to the
module i18n index or shared resources — the `videos` namespace is already registered.
