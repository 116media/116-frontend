# Spec 09 — i18n

The `auth` namespace (en/fr), the shared `validator` namespace keys (consumed by
`zod.errormap.ts`), and resource registration. Both languages must stay
key-aligned.

Design ref: [../14-i18n.md](../14-i18n.md).

- [ ] Register `auth` in `resources.ts`

## Shared `validator` namespace

```ts
// src/shared/presentation/i18n/locales/en/validator.ts
/**
 * validator (en)
 *
 * @description
 * English validation messages, resolved by the zod error map at validation time.
 * Every message names its field via the `{{field}}` interpolation (the localized
 * field label, supplied by `Validators`) — e.g. "Email or username is required".
 * Must stay key-aligned with the French mirror.
 */
export const validator = {
    required: "{{field}} is required",
    email: "{{field}} must be a valid email address",
    invalid: "{{field}} is invalid",
    minLength: "{{field}} must be at least {{min}} characters",
    maxLength: "{{field}} must be at most {{max}} characters",
    passwordStrength: "{{field}} must be at least {{min}} characters with an uppercase, a lowercase and a number",
    otp: "{{field}} must be a 6-digit code",
    mustMatch: "{{field}} does not match",
} as const;
```


## Barrel + registration

```ts
// src/modules/auth/presentation/i18n/locales/en/index.ts
import { common } from "./common";
import { errors } from "./errors";
import { login } from "./login";
import { otp } from "./otp";
import { password } from "./password";
import { session } from "./session";
import { signup } from "./signup";

/**
 * Composes the English `auth` namespace; call sites use `t("auth.login.title")`.
 */
export const en = { common, login, signup, otp, password, session, errors } as const;
```

```ts
// src/modules/auth/presentation/i18n/index.ts
import { en } from "./locales/en";
import { fr } from "./locales/fr";

/**
 * The auth module's i18n messages, registered under the `auth` namespace.
 */
export const authMessages = { en, fr } as const;
```

```ts
// src/shared/presentation/i18n/resources.ts (additions)
import { authMessages } from "@/modules/auth/presentation/i18n";

export const en = { ...sharedEn, articles: /* … */, videos: /* … */, auth: authMessages.en };
export const fr = { ...sharedFr, articles: /* … */, videos: /* … */, auth: authMessages.fr };
```

## Verification

- [ ] `en` and `fr` `auth` namespaces have identical key sets.
- [ ] `validator` namespace populated; a zod failure renders localized in both languages.
- [ ] Validation messages **name the field** — submitting an empty login shows
      "Email or username is required" (en) / "…est obligatoire" (fr), not a generic
      "This field is required".
- [ ] `t("auth.login.title")` and `t("auth.otp.resendIn", { seconds: 42 })` resolve.
- [ ] tsc + biome clean.
