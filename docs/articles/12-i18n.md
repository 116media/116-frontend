# i18n

The listing adds a handful of keys to the existing `articles` namespace (en/fr). All
card and grid copy is translated — no literal strings in components — following the
app's per-file locale convention.

---

## Placement

```
src/modules/articles/presentation/i18n/locales/en/articles.ts
src/modules/articles/presentation/i18n/locales/fr/articles.ts
```

Extend the existing `articles` locale objects with a `card` and a `grid` block. Keep
one file per namespace, no barrel — matching the existing i18n layout.

## Notes

- **Reading time** uses i18next pluralization (`readTime` with `{{count}}`), so
  `1 min read` vs `8 min read` (and the French forms) are handled by the plural rules,
  not string concatenation.
- **Dates** are formatted by the shared relative/absolute date util the video cards use
  (locale-aware), **not** hardcoded like the brief's `"April 20, 2023"`.
- **Category names** come from the data (`categoryName`), not i18n — categories are
  DB-driven on the backend.
- Screen-reader-only labels (`bookmark`, `like`, `comments`) are translated too, so the
  icon-only buttons are announced correctly in both languages.
