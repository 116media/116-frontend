# Internationalization (auth namespace)

The module adds an `auth` i18n namespace following the existing per-module
pattern (`src/modules/<module>/presentation/i18n/locales/{fr,en}/`), composed
into the shared resources. Both `en` and `fr` must stay key-aligned.

---

## Namespace layout

```text
src/modules/auth/presentation/i18n/
├── index.ts                      # exports authMessages = { en, fr }
└── locales/
    ├── fr/
    │   ├── index.ts              # composes the sub-namespaces under `auth`
    │   ├── login.ts
    │   ├── signup.ts
    │   ├── otp.ts
    │   ├── password.ts
    │   ├── session.ts
    │   └── errors.ts
    └── en/  (mirror)
```

Register in `src/shared/presentation/i18n/resources.ts`:

```ts
export const en = { ...sharedEn, articles: …, videos: …, auth: authMessages.en };
export const fr = { ...sharedFr, articles: …, videos: …, auth: authMessages.fr };
```

Call sites: `t("auth.login.title")`, `t("auth.otp.resendIn", { seconds })`.

---

## Suggested keys (per view)

```ts
// auth.login
{ title, subtitle, credentialsLabel, passwordLabel, submit,
  forgotPassword, noAccount, createAccount, invalidCredentials }

// auth.signup
{ title, subtitle, emailLabel, userNameLabel, passwordLabel, submit,
  haveAccount, login, verificationSent }

// auth.otp
{ title, subtitle, codeLabel, submit, resend, resendIn, // "Resend in {{seconds}}s"
  verified, expired, tooManyAttempts }

// auth.password
{ forgotTitle, forgotSubtitle, emailLabel, sendCode,
  resetTitle, newPasswordLabel, confirmPasswordLabel, reset,
  changeTitle, oldPasswordLabel, change, updated, passwordsMustMatch }

// auth.session
{ title, thisDevice, active, expired, revoke, signOut, signOutAll,
  signOutAllConfirm, expiredNotice }     // "Your session expired. Please log in again."

// auth.errors  (form-level, complements shared apiErrors)
{ generic, network, accountInactive, accountNotVerified }
```

---

## Validation messages

Field-level zod messages reference keys (shared `validator` namespace or
`auth.*`), localized by the zod error map (`zod.errormap.ts`) at validation
time. Example mapping:

| zod message key | resolves to |
|---|---|
| `"passwordsMustMatch"` | `auth.password.passwordsMustMatch` |
| `min`/`max`/`email`/`digit` | shared `validator.*` (reuse existing) |

Keep strength-rule wording generic ("at least 6 characters, with upper, lower
and a number") rather than echoing the regex.

---

## Server error → message

The client interceptor maps exception `title` → `apiErrors.*` (already defined
in `src/shared/infrastructure/constants/api.ts`): `authentication`,
`authorization`, `accessTokenExpiry`, `refreshTokenExpiry`,
`accountNotVerified`, `accountInactive`, `validation`. The auth forms surface
these via the existing localized lookup; the `auth.errors` namespace only adds
form-specific copy not already covered.

---

## Language is already wired

The client sends `Accept-Language` from `getClientLanguage()` on every request
(request interceptor), so backend messages come back localized. The auth modal
inherits the app `I18nProvider`; use `suppressHydrationWarning` on streamed
translated text the same way `ShowsSection` does.
