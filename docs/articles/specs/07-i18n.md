## Notes

- **Pluralization:** `readTime` uses i18next plural suffixes (`_one` / `_other`); call
  as `t("articles.card.readTime", { count })`. (English forms coincide; French uses the
  same phrasing but keep both keys for correct plural resolution.)
- **Registration:** the `articles` namespace is already registered; adding nested keys
  needs no new resource wiring. Confirm both locale objects stay structurally identical
  (same keys) so a missing translation can't slip through.
- **No literals in components** — every card/grid string above is referenced via `t(…)`
  (see the card + grid specs). Category names are data (`categoryName`), not i18n.
